# TypeScript Backend

- Use `strict: true` in `tsconfig.json`
- Prefer `interface` over `type` for object shapes, `type` for unions
- Use `unknown` instead of `any`
- Leverage `zod` or `typebox` for runtime validation
- Use `tsx` or `ts-node` for development, compile with `tsc` for production
- Use `@types/node` and framework-specific type packages
- Define shared types in a `types/` or `shared/` directory
